Rahi profile site — GitHub Pages deployment

1. Extract the ZIP contents into the root of the repository used for GitHub Pages.
2. Keep the included CNAME file (rahi.bro.bd) and .nojekyll file.
3. In GitHub: Settings > Pages, select the branch/folder containing index.html and set custom domain to rahi.bro.bd.
4. At your DNS provider, point the rahi subdomain to the GitHub Pages hostname shown in repository settings, then enable HTTPS after DNS verification.
5. After HTTPS works, add the domain to Google Search Console, submit https://rahi.bro.bd/sitemap.xml, inspect the URL, and request indexing.

Search results and AI summaries depend on crawling, indexing and ranking; structured data does not guarantee a rich result. The site allows OpenAI's OAI-SearchBot in robots.txt.
